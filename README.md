# Vukovi kalkulator

Kalkulator ratnog budžeta za WarEra (MU Vukovi). Upišeš ime iz igre, a stranica povuče skilove, opremu, firme, cene i bitke uživo iz WarEra API-ja. Pokaže build sa najviše štete koji te ostavlja u plusu.

Otvori: https://kerkezpetar99-prog.github.io/vukovi-kalkulator/

API ključ nije obavezan. Ako ga upišeš, ostaje samo u tvom browseru i šalje se jedino na api2.warera.io.
